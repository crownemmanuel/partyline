How it works

Up and talking before doors open

  1. 1

    Host on a laptop

    Open the PartyLine desktop app on any Mac, Windows or Linux machine. It starts the audio server, the control server and the admin console. Nothing to configure, nothing to sign up for.

  2. 2

    Crew joins with a code

    Phones on the same Wi‑Fi find the host automatically. Tap it, enter the 6‑digit join code (or scan the QR), type a name. Browsers just open the URL the host shows.

    482197
  3. 3

    Lock the phone. Talk.

    Plug in a headset and pocket the phone. PartyLine runs as an ongoing call, so it keeps working with the screen off. Tomorrow it reconnects on its own, no code needed.

For the producer

Talk to anyone. Hear only what you need.

The host app doubles as the admin console. Talk to one group, several groups, everyone, or a single person. Pick which groups you listen to and solo the ones that matter right now.

  • Talk to all, to a group, or to one device
  • Mute, rename, move or remove any device
  • Force hold‑to‑talk for the noisy ones
  • See who is speaking, battery, headset and latency

Groups

Camera talks to camera. Backstage stays backstage.

Split the team into groups. Each person talks and listens in their own group, and the server enforces who can hear whom, so backstage chatter never ends up in the camera operators' ears.

In the pocket

Built for a whole shift with the screen off.

On iPhone PartyLine uses CallKit, on Android a call‑style foreground service, so the system treats it like a phone call that never drops. Mute from the lock screen, or use the headset button as push‑to‑talk.

  • Keeps running with the phone locked
  • Headset button: latch or push‑to‑talk
  • Messages and attention buzz on the lock screen
  • Warns when there is no headset (echo risk)

Everything else

Small on purpose. Serious where it counts.

Low latency

Opus audio over WebRTC, forwarded by a local media server with no mixing step and no trip to the internet.

Local network only

Everything stays on your Wi‑Fi. Works in venues with no internet at all. Traffic is encrypted with a certificate the host makes on first run.

Join from anything

iPhone app, Android app, the desktop app on another computer, or any modern browser pointed at the host.

Text & quick replies

When nobody can talk: send text to a group or a person, answer with one tap — OK, Standby, Ready — or send an attention buzz.

Devices are remembered

Camera 2 today is Camera 2 tomorrow. Returning devices reconnect to their group without a join code.

Voice isolation

Noise suppression keeps the generator hum and crowd roar out of everyone else's ears.

FAQ

Questions crews ask

Does it need the internet?

No. Everything runs between the host laptop and the devices on the same Wi‑Fi network. A travel router with no uplink works fine.

How many people can join?

PartyLine is designed for small production teams: about 3 to 30 devices, one show at a time.

Will it keep working when my phone is locked?

Yes, on the iPhone and Android apps. PartyLine registers as an ongoing call (CallKit on iPhone, a call‑style foreground service on Android), so it keeps running for a whole shift. Browsers cannot guarantee this, so use the app for anyone who pockets their phone.

Do I need special headsets?

Any wired or Bluetooth headset with a microphone works. A headset is strongly recommended: on speaker the phone can echo, and PartyLine warns you about it.

Push‑to‑talk or open mic?

Both. Each person can hold to talk or latch the mic on. The producer can force hold‑to‑talk on any device.

Why does my browser warn about the certificate?

The host makes its own encryption certificate on first run, because there is no internet authority to sign it on a private network. The native apps verify the host by its fingerprint; in a browser you accept it once.

Is it free?

Yes. PartyLine is open source. No accounts, no subscriptions, no cloud.
